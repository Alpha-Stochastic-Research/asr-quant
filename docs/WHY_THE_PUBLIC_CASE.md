# Why the Public Case Comes First

ASRQuant has a broad API surface, but public adoption is easier when a new user sees one complete workflow before the full catalog.

The EUR-rates practical case was selected because it exposes several important package contracts in one path:

- public market data;
- data quality and provenance;
- fixed-income conventions;
- curve construction;
- instrument pricing;
- market risk;
- P&L explanation;
- scenarios;
- research validation;
- experiment lineage;
- report export.

The notebook is therefore the primary discovery asset, while the full documentation remains the reference surface.
