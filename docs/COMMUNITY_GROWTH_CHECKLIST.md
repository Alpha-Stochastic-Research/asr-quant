# Community Growth Checklist

This checklist supports sustainable ASRQuant adoption.

## Repository

- [x] Discovery-first README
- [x] Install command above the fold
- [x] PyPI / Python / license / stars / download badges
- [x] Public practical notebook
- [x] Colab link
- [x] Clear contribution call to action
- [ ] Label suitable issues with `good first issue`
- [ ] Label contribution-ready issues with `help wanted`
- [ ] Add 2–3 small, well-scoped beginner issues

## Documentation

- [x] Public practical case on documentation homepage
- [x] Public practical case in Getting Started navigation
- [x] Clear ASRQuant 1.3 positioning
- [ ] Add rendered screenshots from the practical case after outputs are stabilized

## Distribution

- [ ] Publish the real-world rates workflow post
- [ ] Publish the quote-space risk post
- [ ] Publish the validation post
- [ ] Publish the reproducibility post
- [ ] Share the practical notebook in appropriate quant/Python communities according to each community's rules

## Measurement

Track weekly rather than optimizing for a one-day spike:

- PyPI download trend;
- GitHub stars;
- forks;
- repository clones / visitors where available;
- documentation traffic;
- external issues;
- first-time contributors;
- repeat contributors;
- external citations / notebooks using ASRQuant.
