# ASRQuant Adoption Metrics

Track adoption on a weekly cadence.

## Discovery

- GitHub repository visitors
- README / notebook views where available
- documentation sessions
- traffic sources

## Activation

- PyPI downloads
- Colab / notebook usage where observable
- repository clones
- quickstart completion proxies such as issue/questions referencing examples

## Engagement

- GitHub stars
- forks
- repeat documentation visitors
- external issues
- pull requests

## Community quality

- first-time external contributors
- repeat contributors
- external citations
- third-party notebooks / projects using ASRQuant

Avoid treating one-day download spikes as the primary success metric.
