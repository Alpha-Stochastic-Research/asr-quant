# ASRQuant User Journey

A new user should be able to move through ASRQuant in this order:

1. **Discover** — understand the package in under 30 seconds from the README.
2. **Install** — copy one `pip install` command.
3. **Run** — open the public practical notebook or Colab.
4. **Understand** — see the research chain from data to validation and lineage.
5. **Deepen** — move into the documentation by domain.
6. **Engage** — star, fork, open an issue or contribute.

This is the intended discovery path for the repository and documentation home pages.
