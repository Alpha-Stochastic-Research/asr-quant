# Technical Outreach Rules

ASRQuant outreach should be useful even to someone who never installs the package.

## Do

- lead with a technical problem;
- show code or a reproducible workflow;
- state assumptions and limitations;
- link to the notebook or documentation;
- use the same install command consistently;
- follow each community's posting rules;
- answer technical questions and bug reports publicly when appropriate.

## Avoid

- artificial download inflation;
- engagement bait;
- unsupported performance claims;
- implying that validation diagnostics prove alpha;
- presenting illustrative market proxies as production market infrastructure;
- mass-posting identical promotional copy across communities.

The long-term growth loop is **technical usefulness → trust → repeat usage → contribution**.
