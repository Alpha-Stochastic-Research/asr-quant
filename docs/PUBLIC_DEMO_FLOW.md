# Public Demo Flow

Recommended 20–25 minute ASRQuant demonstration:

1. **2 min — Positioning**: auditable quantitative-finance research in Python.
2. **3 min — Data**: ECB curve + data validation + snapshot fingerprint.
3. **3 min — Curve**: PCA + explicit curve states.
4. **4 min — Instrument & risk**: 5Y payer IRS, DV01, key-rate DV01, quote PV01.
5. **3 min — Explain & stress**: realized P&L explanation + three curve scenarios.
6. **4 min — Validation**: specification universe, CPCV, PBO, Reality Check, SPA.
7. **3 min — Reproducibility**: Experiment, registry, report export.
8. **1 min — Close**: install command + GitHub / docs / notebook links.

Keep the public message centered on the workflow rather than the raw number of functions in the package.
