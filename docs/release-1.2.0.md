# Release 1.2.0

**Release:** ASRQuant 1.2.0  
**Date:** 19 August 2026

Version 1.2.0 is a structural and quantitative-research release. It preserves the established 1.x APIs while introducing a more coherent domain-oriented public interface.

## Main additions

- canonical domain namespaces and verbs;
- data facade and validation contract;
- data-driven and literature-linked hypothesis discovery;
- cross-sectional alpha research;
- factor research and decomposition;
- portfolio VaR / Expected Shortfall and contribution analysis;
- market-microstructure diagnostics;
- consistent result and exception contracts.

## Preserved areas

The release retains the existing discovery, interest-rate, derivatives, simulation, volatility, backtesting, paper-trading and production-readiness layers.

## Execution boundary

Live-capable broker primitives remain fail-closed. Package installation does not authorize capital deployment.
