# README Discovery Notes

The repository README is intentionally shorter than the full documentation.

Its role is to answer, quickly:

1. What is ASRQuant?
2. Why would a quantitative-finance researcher use it?
3. Can I install it immediately?
4. Is there a real workflow I can run now?
5. Where are the detailed docs?

Detailed API and methodology material remains in the documentation site rather than being duplicated on the GitHub landing page.
