# ASRQuant Growth Sprint Summary

This sprint focuses on **real user adoption** by reducing the distance between discovering ASRQuant and running a credible quantitative-finance workflow.

## Changes in this sprint

- discovery-first GitHub README;
- dynamic PyPI / Python / license / star / download badges;
- public real-world notebook above the fold;
- one-click Google Colab entry point;
- documentation homepage centered on the practical case;
- practical-case page in Getting Started;
- reusable technical launch posts;
- community growth checklist;
- adoption metrics and distribution playbook;
- PyPI metadata/version-alignment notes for the next release workflow.

## Core public case

**ECB EUR curve → 5Y payer IRS → DV01 / key-rate DV01 / quote PV01 → P&L explain → stress → CPCV / PBO / Reality Check / SPA → experiment lineage → research report**

## Success criterion

Not a temporary download spike. Success means more users can:

1. discover the project;
2. install it quickly;
3. reproduce a real workflow;
4. understand why its validation / lineage model is useful;
5. return, report issues, star, fork or contribute.
