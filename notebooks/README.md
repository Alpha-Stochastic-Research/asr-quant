# ASRQuant notebooks

## ASRQuant_v1.2.0_Quickstart.ipynb

A deterministic end-to-end introduction to the public ASRQuant 1.2.0 API.

From the repository root:

```bash
python -m pip install -e .
jupyter lab notebooks/ASRQuant_v1.2.0_Quickstart.ipynb
```

The notebook asserts that the imported package version is `1.2.0` before running the examples.
