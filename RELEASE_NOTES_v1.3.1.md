# ASRQuant 1.3.1

ASRQuant 1.3.1 is the corrected production publication of the final 1.3 codebase pushed to the repository on 26 September 2026.

## Why 1.3.1

PyPI package versions are immutable. Because version 1.3.0 had already been published, the corrected final source is released as 1.3.1 rather than attempting to overwrite 1.3.0.

## Scope

This patch release preserves the ASRQuant 1.3 feature set and publishes the final audited source currently on `main`, including quantitative research infrastructure, fixed-income and rates analytics, risk and portfolio tooling, backtesting, validation, reproducibility, and research workflow capabilities.

## Installation

```bash
pip install --upgrade asrquant==1.3.1
```
