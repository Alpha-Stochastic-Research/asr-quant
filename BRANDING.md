# ASRQuant brand assets

ASRQuant has a dedicated package identity derived from the Alpha Stochastic Research visual system.

<p align="center">
  <img src="docs/assets/brand/asrquant-logo.svg" alt="ASRQuant logo" width="760">

## Assets

- `docs/assets/brand/asrquant-mark.svg` — compact package mark for favicons, navigation, badges and icon surfaces.
- `docs/assets/brand/asrquant-logo.svg` — complete ASRQuant wordmark for documentation and repository presentation.

## Usage

Use the compact mark when the available space is icon-sized. Use the full wordmark for documentation covers, repository presentation and package-specific communication.

The ASRQuant identity is package-specific. It should not replace the Alpha Stochastic Research organization logo in contexts representing ASR as a whole.
